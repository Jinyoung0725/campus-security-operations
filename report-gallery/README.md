## 원본 보관 방식

제공된 프로젝트 결과 자료에서 추출한 이미지입니다. 같은 화면이 여러 곳에 등장해도 각 이미지 항목을 보존했습니다.
문서의 벡터 도형과 텍스트는 이 목록의 범위에 포함되지 않습니다.
원본 화면을 그대로 보존했으므로 일부 이미지에는 실습망 주소, 계정명, 이메일 주소와 공격 로그가 보입니다.
보고서 PDF는 이 저장소에 포함되어 있지 않습니다.
