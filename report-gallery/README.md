# 보고서 이미지 갤러리

사용자가 제공한 248쪽 결과 보고서에서 추출한 이미지 자료입니다. 페이지와 해당 페이지 안의 순서로 파일명을 붙였습니다.
동일한 이미지가 보고서에 다시 등장해도 원래 위치를 확인할 수 있도록 각 등장 항목을 보존했습니다.
문서의 벡터 도형과 텍스트는 이 목록의 범위에 포함되지 않습니다.
원본 화면을 그대로 보존했으므로 일부 이미지에는 실습망 주소, 계정명, 이메일 주소와 공격 로그가 보입니다.

- 이미지 항목: **363개**
- 이미지가 있는 페이지: **174쪽**
