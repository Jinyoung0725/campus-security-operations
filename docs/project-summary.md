# 프로젝트 범위와 결과 요약

> 출처: 사용자 제공 「3차 프로젝트 보고서 — 대학 IT 인프라 구축 및 모의해킹 기반 통합 보안관제 체계 구현」. 이 문서는 원본 248쪽 보고서의 포트폴리오용 요약입니다.

## 목표

대학 본교·분교와 연구·학사·관리 영역에 필요한 네트워크 및 서버 서비스를 구성하고, 승인된 모의해킹을 통해 접근 통제와 관제 체계가 실제로 동작하는지 확인했습니다.

## 구축 범위

| 영역 | 보고서에 기록된 구성 |
| :--- | :--- |
| 캠퍼스 네트워크 | VLAN 분리, 동적·정적 라우팅, 캠퍼스 간 IPsec VPN, ACL·NAT, 게이트웨이·방화벽·링크 이중화 |
| 서버·애플리케이션 | 학사 웹, 메일, 연구자료 공유, DNS, DB 복제, 로드 밸런싱, 백업, 구성 자동화 |
| 다층 방어 | 방화벽, 호스트 접근 통제, 웹 방화벽, 메일 악성 파일 검사, IDS와 계정 보호 |
| 로그·모니터링 | 중앙 로그 수집과 정규화, SIEM 분석, 호스트·서비스·자원 상태 모니터링 |

## 검증 방식

보고서의 모의해킹은 승인된 대상·기간·역할을 정한 뒤 수행되었습니다. 공격 흐름별로 서비스 로그, 네트워크 증적, 호스트 이벤트와 운영 지표를 비교하고, 확인된 취약점에 대한 조치와 탐지 한계를 기록했습니다.

## 해석 시 주의

보고서의 달성률은 팀의 자체 평가입니다. 공개 검증 수치나 제품 성능 지표로 해석하지 않습니다. 일부 개별 항목은 장애 전환 또는 탐지 증거가 불충분했다고 보고되어 있어, 이 저장소는 검증된 사실과 후속 과제를 구분해 적습니다.
